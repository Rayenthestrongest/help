
# Méthode des J — Electron

- Dossier de sauvegarde choisi **une fois**, mémorisé automatiquement.
- Copie sécurité **toutes les 5 min** (aucun réglage nécessaire).
- Indicateurs **Dernière sauvegarde** / **Total copies** mis à jour et persistants.

## Utilisation
1) `npm install`
2) `npm start` → au 1er lancement, choisis le dossier. Ensuite, plus besoin.
3) (optionnel) `npm run build:win` → crée `dist/MethodeJ-win32-x64/MethodeJ.exe`.

Les données sont écrites dans `pass_j_data.json` à l’intérieur du dossier choisi.
